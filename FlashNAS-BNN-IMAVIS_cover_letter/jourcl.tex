\Introduction{We submit the revised manuscript titled ``\pTitle'' for consideration for publication in \pJournalName. We thank the editor for the constructive comments, which have helped us improve the technical clarity, experimental reporting, and presentation of the manuscript. A point-by-point response accompanies this submission. \\
The manuscript presents FlashNAS-BNN, a chain-structured binary neural architecture search framework for efficient image classification across heterogeneous platforms. It combines a chain information-flow accuracy predictor (CIF-Net), a two-stage search strategy that reuses accuracy-screened candidates, and cross-platform latency estimation (CLE) to select architectures according to device latency. \\
\textbf{Search efficiency.} For a given benchmark group, offline preparation requires 1363.20 GPU-hours, including accuracy-label generation and CIF-Net fitting. Online search takes 1.01 GPU-hours for the first platform and 0.48 GPU-hours for each additional platform when the same predictor and screened candidate set are reused. If a new dataset requires a separately trained predictor, its offline preparation cost must be accounted for again. \\
\textbf{Deployment efficiency.} On ImageNet-100, the platform-specific FlashNAS-BNN variants reduce mean latency relative to ReActNet-A by 47.1\% on CPU, 16.0\% on GPU, and 6.8\% on FPGA, while achieving higher Top-1 accuracy in these comparisons. On CPU, FlashNAS-BNN-G achieves 164.57\,ms at 81.40\% Top-1 accuracy; its latency is 61.8\% lower than the NAS-BNN variant without CLE and 39.6\% lower than the variant with CLE, at comparable accuracy. These comparisons support latency-aware binary model design for resource-constrained visual applications.}
